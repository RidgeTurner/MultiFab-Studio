MultiFab Studio is a 7-page custom digital fabrication website featuring on-demand services for 3D printing, laser cutting, pen plotting, sticker cutting, professional design services, and studio policies. Built for the Hack Club Terra challenge.

How it was built
- Built using standard HTML5 and CSS3, utilizing a centralized external stylesheet (style.css), CSS Grid fleet tables, CSS column masonry image galleries, and interactive details FAQ accordions.
- Designed with an industrial color palette (deep blue #0066cc and dark navy #0f172a), pill-shaped navigation with active-page indicators, and consistent responsive light-theme footers.
- Fully audited and polished across all 7 pages (index.html, 3dprinting.html, lasercutting.html, penplotting.html, stickercutting.html, designservices.html, and everythingelse.html) for clean UI, semantic markup, and zero-error code.
